# tymur.fun

Главная страница со всеми проектами — как neal.fun. Каждая карточка ведёт на свою игру или сайт.

- `index.html` — вся страница в одном файле. Картинки карточек нарисованы кодом (SVG).
- Новый проект: добавь строку в массив `projects` и картинку в объект `art` внутри `index.html`.

Сайт: https://tymurius2-arch.github.io/tymur.fun/
